# Website Quản Lý & Bán Đồng Hồ

Website thương mại điện tử bán đồng hồ được xây dựng bằng **ASP.NET MVC**, kết hợp **Entity Framework, SQL Server và Web API**. Hệ thống hỗ trợ khách hàng mua sắm trực tuyến và cung cấp khu vực quản trị cho Admin.

## 🚀 Chức năng

### Khách hàng
- Đăng ký, đăng nhập và quản lý tài khoản
- Xem, tìm kiếm và lọc sản phẩm
- Xem chi tiết sản phẩm
- Thêm, sửa, xóa sản phẩm trong giỏ hàng
- Đặt hàng
- Xem lịch sử và chi tiết đơn hàng
- Bình luận và đánh giá sản phẩm
- Xem chương trình khuyến mãi

### Admin
- Dashboard quản trị
- Quản lý sản phẩm
- Quản lý loại sản phẩm
- Quản lý thương hiệu
- Quản lý khách hàng
- Quản lý tài khoản
- Quản lý đơn hàng
- Quản lý khuyến mãi
- Quản lý bình luận
- Xem báo cáo sản phẩm và doanh thu

### API
- Cung cấp dữ liệu loại sản phẩm thông qua **ASP.NET Web API**
- Trao đổi dữ liệu dưới định dạng **JSON**

## 🛠️ Công nghệ

- **C#**
- **ASP.NET MVC**
- **ASP.NET Web API**
- **Entity Framework**
- **SQL Server**
- **HTML5 / CSS3**
- **JavaScript / jQuery**
- **Bootstrap**
- **JSON**
